# Exact authored-source Copy capability

Add a default-off host capability for an exact authored-source carrier. Preserve
older RenderOptions constructor descriptors and expose the new component explicitly
in record identity/reflection. Source payloads use canonical unpadded base64url of
strict UTF-8, preserving authored CR/LF and BOM within the 4096 UTF-16-unit domain.

This branch is under implementation: the renderer and Copy control are not yet
wired at this intermediate checkpoint. Full rendering, interaction, compatibility
and served validation must precede release.
