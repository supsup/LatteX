# Copy the exact authored LaTeX

Add an explicit default-off host gate for a Copy LaTeX chip in the existing FX
assets. Preserve original input through a strict bounded UTF-8/base64url carrier,
including authored line endings and BOMs. Coupled display and inline APIs carry
that source while retaining SVG and baseline metrics. The control supports a
one-item keyboard/touch menu, reduced motion and accurate clipboard outcomes.

Older RenderOptions constructor descriptors remain callable with the gate off;
the new component participates in record identity/reflection. The author key
data.source is intentionally reserved and rejected, including with the gate off.
No Replay, Graph or body-click shortcut is introduced.

This source candidate is unverified until its complete JVM/API, causal, native
browser/geometry/focus/clipboard and release checks succeed.
